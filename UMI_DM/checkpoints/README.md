# Piper UMI checkpoints

These are the latest local checkpoints from the `my_session2_20261114` training runs.
The files are stored with Git LFS because they exceed GitHub's normal file-size limit.

- `umi_my_session2_20261114_act_latest.ckpt`: ACT UMI policy checkpoint.
- `umi_my_session2_20261114_dp_latest.ckpt`: Diffusion Policy UMI checkpoint.

The checkpoints are inference/training artifacts; the corresponding dataset and local
runtime environment are not included in this repository.
